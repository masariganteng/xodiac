# XODIAC — IX. IN TO YOU
Microsite recreation based on the supplied mockup and assets.

## Files
- `index.html` — landing page
- `styles.css` — responsive visual styling
- `script.js` — live event countdown and ticket-sale state
- `assets/` — supplied artwork/logos

## Notes
- Event date is set to 28 November 2026.
- Countdown currently targets 19:00 Jakarta time as a placeholder because the supplied mockup specifies the date/venue but not the event start time. Change `eventDate` in `script.js` when the confirmed show time is available.
- Ticket sales open at 15 October 2026, 13:00 Jakarta time, based on the supplied mockup.
- No ticketing URL was supplied, so the button is intentionally not linked to an invented destination.
- The page is responsive for desktop/tablet/mobile.
